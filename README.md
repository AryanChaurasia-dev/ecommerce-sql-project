# E-Commerce Sales Analysis using MySQL

A SQL-based project analyzing e-commerce sales data, covering database design, sample data population, and analytical queries for business insights such as revenue trends, customer behavior, and product performance.

## Repository Structure

| File | Description |
|------|--------------|
| `schema.sql` | Database structure — tables, columns, primary and foreign keys, relationships |
| `data.sql` | Sample data for testing and analysis |
| `queries.sql` | SQL queries for business analysis (revenue, top products, customer trends, etc.) |

## Tools

- MySQL
- MySQL Workbench / VS Code

## Setup

1. Run `schema.sql` to create the database and tables.
2. Run `data.sql` to populate sample data.
3. Run `queries.sql` to execute the analysis.

## Overview

This project demonstrates:
- Relational database design for an e-commerce system
- SQL querying techniques including joins, aggregations, and filtering
- Business-focused data analysis using MySQL
